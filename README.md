# 16 meses contigo

Una pequeña página romántica para celebrar 16 meses juntos. Está hecha en un único `index.html`, sin dependencias ni proceso de compilación.

## Verla localmente

Abre `index.html` en cualquier navegador. Pulsa **Abrir mi carta** para leer el mensaje completo.

La página se adapta a móviles y respeta la preferencia del dispositivo para reducir las animaciones.
